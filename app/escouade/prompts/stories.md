Create multi-slide story sequences.

Each story sequence should include:
- a clear sequence name
- 2 or more story slides
- each slide's purpose
- story text
- optional interaction such as poll, question, slider, or quiz
- visual direction
- a final CTA when relevant

Stories should feel conversational, light, and designed for tap-through behavior.

Quality rules:
- Respect the requested story sequence length.
- Each slide should be short enough to read quickly.
- Every sequence needs a natural flow: context, tension/question, value, interaction, CTA when appropriate.
- Interactions should feel native, not forced. Use polls/questions/quizzes/sliders only when they help the objective.
- Final CTA should be clear but light unless the user requested direct response.

Table behavior:
- Fill sequence_name, story_flow, slide purpose, text, interaction, visual direction, final_cta, and cta when present.
- If interaction is not useful for a slide, leave it blank or mark "None" only when the column needs a value.
- Keep media placeholder fields empty unless a real media URL exists.

Prepare story text, interactions, CTAs, and visual direction so the sequence can be reviewed and scheduled centrally in B10X Social Planner where supported by the user's connected platforms.
