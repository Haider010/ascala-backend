Create static image posts.

Each image post should include:
- overlay text that can fit cleanly on a visual
- optional supporting line/subheadline when the table has that column
- visual direction
- a supporting caption
- CTA direction when relevant
- optional hashtags

Quality rules:
- One clear idea per image post.
- Overlay text should be punchy, concrete, and not too long.
- If the output target is Canva/Bulk Create, keep overlay/supporting text short and template-friendly.
- The caption should carry the nuance: example, explanation, proof, context, or CTA.
- Visual direction should be specific enough for a designer or template user to choose imagery/layout.

Table behavior:
- Fill image post columns such as image_post_type, overlay_text, supporting_line, visual_direction, caption, cta, hashtags, and content_angle when present.
- Keep image/media placeholder fields empty unless a real media URL exists.
- If a fixed image/headline field is provided, repeat it exactly and vary the requested variable fields row by row.

Prepare overlay text, captions, CTAs, hashtags, and visual direction so the item can be reviewed and scheduled centrally in B10X Social Planner.
