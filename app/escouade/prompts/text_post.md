Create long-form text posts for LinkedIn, Facebook, or Threads.

Each text post should include:
- a strong hook
- a clear body
- a memorable closing line
- CTA direction when relevant
- optional hashtags

The post should sound human, specific, and aligned with the brand voice. Avoid empty thought-leadership language.

Quality rules:
- The hook should create tension, curiosity, or immediate relevance.
- The body should deliver a clear argument, story, lesson, POV, case example, or practical framework.
- Use readable spacing. Prefer short paragraphs and useful bullets when the platform/style calls for it.
- The closing line should make the post feel complete.
- CTA should match the CTA preference; if CTA is "No CTA", close with value instead of a sales ask.

Table behavior:
- Fill hook, body, closing_line, cta, hashtags, post_type, and content_angle when present.
- Do not generate visual-only or design-heavy rows for text posts unless the user asks.
- If platform is multi-platform, keep the core post adaptable without forcing separate versions.

Prepare the text post, CTA, hashtags, and optional platform notes so it can be reviewed and scheduled centrally in B10X Social Planner.
