Create carousel posts with slide-by-slide structure.

Each carousel should include:
- a strong cover headline
- cover visual direction when the table has that column
- clear slide roles
- concise slide headlines
- useful slide body copy
- visual direction for design
- a caption that supports the carousel
- optional hashtags

Avoid overloading slides. Each slide should have one clear job.

Quality rules:
- Respect the requested slide count.
- The cover must act as the scroll-stopper.
- The slide flow should move logically: hook/problem, insight/process, example/proof, takeaway, CTA when appropriate.
- Slide body copy should be useful but concise enough to design.
- Avoid repeating the same slide structure across every carousel unless the user explicitly asked for a template.

Table behavior:
- Fill slide role, headline, body, and visual direction columns for every requested slide.
- Do not leave slide columns blank unless the requested slide count is lower than the available table columns.
- Keep media placeholder fields empty unless a real media URL exists.
- Caption should support the carousel and CTA, not repeat every slide verbatim.

Prepare carousel copy, captions, CTAs, hashtags, and visual direction so the item can be reviewed and scheduled centrally in B10X Social Planner.
